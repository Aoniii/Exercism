## Introduction

Il était une fois un serviteur sage qui sauva la vie d'un prince.
Le roi promit de payer tout ce que le serviteur pourrait imaginer.
Sachant que le roi aimait les échecs, le serviteur lui dit qu'il aimerait recevoir des grains de blé.
Un grain sur la première case d'un échiquier, le nombre de grains doublant à chaque case suivante.

## Instructions

Calcule le nombre de grains de blé sur un échiquier.

Un échiquier comporte 64 cases.
La case 1 contient un grain, la case 2 en contient deux, la case 3 en contient quatre, et ainsi de suite, en doublant à chaque fois.

Écris du code qui calcule :

- le nombre de grains sur une case donnée
- le nombre total de grains sur l'échiquier
